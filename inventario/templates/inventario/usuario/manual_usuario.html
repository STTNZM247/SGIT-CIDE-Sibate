Manual del sistema

{% if rol_manual == 'admin' %} Guía para administración integral: catálogos, inventario, pedidos, préstamos, auditoría y usuarios. {% elif rol_manual == 'almacenista' %} Guía para operación de almacén: inventario, pedidos y préstamos. {% else %} Guía para uso del portal de usuario: catálogo, carrito, pedidos y perfil. {% endif %}

{% if rol_manual == 'admin' %}

1. Gestión del catálogo

  1. Ingresa a Catálogo y crea categorías principales.
  2. Usa subcategorías para organizar por niveles según el tipo de material.
  3. Mueve productos entre subcategorías con arrastrar y soltar.
  4. Si te equivocas en un movimiento, usa Ctrl+Z para revertir.

2. Inventario y trazabilidad

  1. En Inventario revisa stock, ubicación y estado de productos.
  2. Consulta la trazabilidad para ver en qué ruta de subcategorías está cada producto.
  3. Usa los enlaces de trazabilidad para abrir directamente el contexto en Catálogo.

3. Pedidos, préstamos y auditoría

  1. Aprueba o rechaza pedidos según disponibilidad real.
  2. Registra entregas y devoluciones para mantener consistencia de stock.
  3. Usa Auditoría para rastrear cambios críticos (crear, mover, eliminar y restaurar).

4. Usuarios

  1. Crea usuarios nuevos con rol inicial correcto.
  2. Gestiona estados (activo/inactivo) y cambios de rol según permisos.
  3. Verifica solicitudes de validación SENA cuando aplique.
{% elif rol_manual == 'almacenista' %}

1. Inventario operativo

  1. Revisa stock y cantidades antes de confirmar entregas.
  2. Actualiza ubicaciones y datos del producto cuando cambien físicamente.
  3. Usa Catálogo para ubicar rápido elementos por subcategoría.

2. Gestión de pedidos

  1. Abre Pedidos para validar cada solicitud.
  2. Marca productos no disponibles cuando no haya existencias reales.
  3. Confirma entrega con código para dejar trazabilidad de despacho.

3. Préstamos y devoluciones

  1. Consulta fechas de devolución en panel de préstamos.
  2. Registra devoluciones para restituir stock automáticamente.
  3. Monitorea vencidos y coordina recuperación de elementos pendientes.
{% else %}

1. Consultar productos

  1. Desde el panel de usuario revisa disponibilidad por producto.
  2. Abre el detalle para confirmar descripción y cantidad existente.
  3. Agrega al carrito solo los productos que realmente necesitas.

2. Solicitar pedidos

  1. En carrito ajusta cantidades antes de enviar.
  2. Confirma ubicación/área para facilitar la entrega.
  3. Revisa notificaciones del sistema para conocer estado del pedido.

3. Perfil y seguridad

  1. Actualiza teléfono, programa y centro en Perfil.
  2. Usa la opción Cambiar contraseña para reforzar tu acceso.
  3. No compartas tu contraseña ni códigos de entrega.
{% endif %}

Buenas prácticas

  • Mantén la información actualizada para evitar errores de inventario.
  • Trabaja siempre desde tu cuenta, sin compartir credenciales.
  • Reporta cualquier inconsistencia al equipo de soporte.
